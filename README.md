LAB03_TAIS - Aplicación Web de Pronóstico del Clima (weather-forecast-app)Plataforma web Single Page Application (SPA) de cliente ligero desarrollada en TypeScript vanilla (sin dependencias de frameworks pesados ni servidor backend propio) para consultar el pronóstico meteorológico actual de cualquier ciudad del mundo en tiempo real.📌 Características PrincipalesConsulta en Tiempo Real: Integración directa y gratuita con las APIs REST de Open-Meteo (Geocodificación y Pronóstico).Arquitectura Modular por Capas: Estructurada formalmente en Presentación, Controlador (Patrón Mediador), Servicios de Negocio y Clientes HTTP.Resiliencia y Control de Errores:Control de timeouts a los 10 segundos mediante AbortController.Manejo explícito de caídas de red, códigos de estado HTTP no-2xx y respuestas JSON malformadas.Mapeo y discriminación de ciudades no encontradas (CITY_NOT_FOUND).Validación Síncrona de Entradas:Rechazo inmediato de entradas vacías o compuestas únicamente por espacios en blanco.Saneamiento de texto (trim()) y límite de 100 caracteres (maxlength="100").Formateo Estricto de Métricas: Normalización visual con redondeos exactos y unidades de medida para Temperatura (°C), Humedad (%) y Precipitación (mm).🛠️ Tecnologías UtilizadasLenguaje: TypeScript (Modo Estricto)Entorno de Pruebas: Vitest, jsdom, @testing-library/dom y fast-check (Pruebas basadas en propiedades).APIs Externas:Open-Meteo Geocoding APIOpen-Meteo Forecast API📁 Estructura del ProyectoSDD Project/

🚀 Instalación y Ejecución LocalClonar el repositorio:git clone https://github.com/klismannSis/LAB03_TAIS.git
cd LAB03_TAIS
Navegar a la carpeta del proyecto e instalar dependencias:cd "SDD Project"
npm install
Ejecutar en entorno de desarrollo:npm run dev
Compilar para producción:npm run build
